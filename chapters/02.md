## 十三、为什么调用的是 `model(x)`？

林默突然发现一个奇怪的地方。

我们明明定义的是：

```python
def forward(self, x):
    ...  # 此处只展示结构，完整代码见上下文
```

但真正使用的时候却通常写：

```python
y = model(x)
```

而不是：

```text
y = model.forward(x)
```

“为什么？”

教授说：

“因为 `nn.Module` 实现了调用机制。”

你写：

```python

```

PyTorch 会经过 `Module` 自己的调用流程，最终执行你的：

```text
forward(x)
```

可以粗略理解成：

```text
model(x)
   │
   ▼
Module.__call__()
   │
   ├── 一些 PyTorch 内部处理
   │
   ▼
forward(x)
   │
   ▼
结果
```

所以一般：

> **调用模型用 `model(x)`，不要手动直接调 `model.forward(x)`。**

## 十五、把模型真正训练起来

不过教授没有马上结束。

“先把今天所有东西拼起来。”

```python
import torch
import torch.nn as nn

# 1. 数据
x = torch.tensor([
    [1.0, 2.0],
    [2.0, 3.0],
    [3.0, 4.0]
])

target = torch.tensor([
    [3.0],
    [5.0],
    [7.0]
])


# 2. 模型
class MyNet(nn.Module):

    def __init__(self):
        super().__init__()

        self.fc1 = nn.Linear(2, 4)
        self.fc2 = nn.Linear(4, 1)

    def forward(self, x):

        x = self.fc1(x)
        x = torch.relu(x)
        x = self.fc2(x)

        return x


model = MyNet()


# 3. 损失函数
loss_fn = nn.MSELoss()


# 4. 优化器
optimizer = torch.optim.SGD(
    model.parameters(),
    lr=0.01
)


# 5. 训练
for epoch in range(1000):

    optimizer.zero_grad()

    pred = model(x)

    loss = loss_fn(pred, target)

    loss.backward()

    optimizer.step()
```
