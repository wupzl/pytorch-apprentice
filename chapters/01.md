## 六、梯度其实就是“往哪边走”

教授画了一座山谷：

```text
Loss
 ^
 |       *
 |      / \
 |     /   \
 |    /     \
 |   /       \
 |__/_________\____> w
          ↓
       最低点
```

神经网络训练，本质上是在找：

> **Loss 最低的位置。**

而梯度告诉你：

```text
当前位置的坡度
```

假设：

```text
gradient > 0
```

说明往右走，Loss 变大。

所以应该：

```text
往左走
```

也就是：

```text
w = w - learning_rate * gradient
```

林默突然盯住了这个公式。

“等等……”

```text
新参数
=
旧参数
-
学习率 × 梯度
```

教授点头。

“这就是你以后天天见到的——”

> **梯度下降。**

## 七、第一次真正的“训练”

教授打开编辑器。

“现在不用任何神经网络 API。”

“我们手搓一次训练。”

目标：

\[

\]

训练数据只有一个：

```text
x = 5
y = 10
```

代码：

```python
import torch

w = torch.tensor(1.0, requires_grad=True)

x = torch.tensor(5.0)
target = torch.tensor(10.0)

for i in range(10):

    y = w * x

    loss = (y - target) ** 2

    loss.backward()

    with torch.no_grad():
        w -= 0.01 * w.grad

    w.grad.zero_()

    print(w.item(), loss.item())
```

林默看着这段代码。

只有十几行。

但教授告诉他：

“你已经写出了一个极简版机器学习训练系统。”

## 八、逐行拆开

第一句：

```python
w = torch.tensor(1.0, requires_grad=True)
```

`w` 是我们想学习的参数。

初始：

```text
w = 1
```

但正确答案应该接近：

```text
w = 2
```

---

第二步：

```text
y = w * x
```

这叫：

> **Forward / 前向传播**

拿当前参数计算预测结果。

例如：

```text
w = 1
x = 5

y = 5
```

但是正确答案：

```text
target = 10
```

---

第三步：

```text
loss = (y - target) ** 2
```

计算：

```text
预测得有多烂
```

这就是：

> **Loss Function / 损失函数**

预测：

```text
5
```

答案：

```text
10
```

于是：

```text
loss = 25
```

---

第四步：

```python
loss.backward()
```

这一句话极其重要。

PyTorch 开始沿着计算图：

```text
Loss
 ↑
 y
 ↑
 w
```

反向计算：

\[
\frac{\partial Loss}{\partial w}
\]

这就是：

> **Backward / 反向传播。**

---

第五步：

```text
w -= 0.01 * w.grad
```

根据梯度修改参数。

其中：

```text
0.01
```

叫：

> **Learning Rate / 学习率。**

---

第六步：

```text
w.grad.zero_()
```

林默突然问：

“为什么要清零？”

教授笑了。

“这是 PyTorch 新手最容易踩的坑之一。”

## 九、梯度默认会累加

假设第一次：

```text
w.grad = 3
```

第二次又算出：

```text
w.grad = 4
```

很多初学者以为最后：

```text
w.grad = 4
```

实际上 PyTorch 默认可能变成：

```text
w.grad = 7
```

因为：

> **PyTorch 的梯度默认累加。**

所以每轮训练通常需要：

```text
optimizer.zero_grad()
```

或者刚才手写版本里的：

```text
w.grad.zero_()
```

林默把这句话记在笔记里：

> backward 之前/每轮训练要注意清梯度，否则梯度会累积。

## 十、为什么更新参数要 `torch.no_grad()`？

还有一段奇怪代码：

```python
with torch.no_grad():
    w -= 0.01 * w.grad
```

教授问：

“我们修改 `w` 的这个操作，需要参与神经网络学习吗？”

“不需要。”

“那就没必要把它记录进计算图。”

所以：

```python
with torch.no_grad():
    ...  # 此处只展示结构，完整代码见上下文
```

意思可以暂时理解成：

> **接下来这些计算不用追踪梯度。**

这不仅减少额外记录，也避免对需要梯度的叶子 Tensor 做不合适的原地更新。
