## 八、Q、K、V 是怎么来的？

教授把上章输出拿出来。

经过 Embedding 后：

```text
x
shape:
[batch, seq_len, hidden_dim]
```

例如：

```text
[1, 5, 512]
```

意思：

```text
1 个句子
5 个 Token
每个 Token 512 维
```

然后模型拥有三组可学习矩阵：

\[
W_Q,\ W_K,\ W_V
\]

计算：

\[
Q=XW_Q
\]

\[
K=XW_K
\]

\[
V=XW_V
\]

林默问：

“又是 Linear？”

“对。”

PyTorch 里完全可以理解成：

```python
self.q_proj = nn.Linear(hidden_dim, head_dim)
self.k_proj = nn.Linear(hidden_dim, head_dim)
self.v_proj = nn.Linear(hidden_dim, head_dim)
```

所以：

> Q、K、V 并不是凭空出现的。

它们是：

> 同一个输入表示，经过三种不同的可学习线性投影得到的。

## 九、为什么同一个 Token 要生成三个版本？

林默问：

“直接用原始 Embedding 比不行吗？”

教授说：

比如：


作为 Query：

```text

```

作为 Key：

```text
别人为什么应该关注我？
```

作为 Value：

```text
如果别人关注我，我提供什么信息？
```

这三种角色不一定需要使用同一个向量空间。

所以模型学习：

```text
W_Q
W_K
W_V
```

把原始表示变成三套不同表示。

## 十、Q 和 K 怎么算相关性？

教授写出最核心的一步：

\[
QK^T
\]

林默：

“矩阵乘法？”

“对。”

先看一个 Token。

假设：

```text
Q = [1, 2]
```

苹果手机的：

```text
K1 = [1, 3]
```

桌子的：

```text
K2 = [-1, 0]
```

点积：

\[
Q\cdot K_1
=
1\times1+2\times3
=
7
\]

而：

\[
Q\cdot K_2
=
1\times(-1)+2\times0
=
-1
\]

于是：

```text
苹果手机：7
桌子：-1
```

很自然：

> 苹果手机相关性更高。

---

## 十一、点积到底代表什么？

两个向量：

\[
a\cdot b
\]

可以写成：

\[
|a||b|\cos\theta
\]

所以当方向更相似：

```text
点积通常更大
```

在 Attention 里：

> Query 和 Key 点积越大，可以理解为它们越匹配。

因此：

```text
Q × K^T
```

会一次性算出：

> 每个 Query 和所有 Key 的匹配分数。

---

## 十二、整个 Attention Score 矩阵

假设有 4 个 Token：

```text
A
B
C
D
```

每个 Token 都生成：

```text
Q
K
```

那么：

\[
QK^T
\]

会得到一个：

```text
4 × 4
```

矩阵：

```text
          K_A   K_B   K_C   K_D

Q_A       2.1   0.3   1.7   0.1

Q_B       0.2   3.4   0.8   1.1

Q_C       1.9   0.7   2.5   0.4

Q_D       0.1   1.2   0.5   3.1
```

每一行：

> 一个 Token 在看所有 Token。

例如：

```text
Q_C
```

这一行：

```text
C 对 A 的关注分数
C 对 B 的关注分数
C 对 C 的关注分数
C 对 D 的关注分数
```

## 十三、为什么还要除以 √d？

教授终于写完整：

\[
\frac{QK^T}{\sqrt{d_k}}
\]

林默问：

“这个 `√d` 到底是干嘛？”

教授说：

“如果向量维度很大，点积容易变得很大。”

比如：

维度只有 2：

```text
点积可能：
2
5
-3
```

维度变成 512：

很多项加起来。

结果可能：

```text
50
100
-70
```

然后 Softmax：

```text
[50, 100, -70]
```

会变得极端：

```text
≈ [0, 1, 0]
```

一旦 Softmax 太饱和：

梯度可能变得很小。

所以除以：

\[
\sqrt{d_k}
\]

把数值缩小到更稳定的范围。

这就是：

> Scaled Dot-Product Attention

里的：

### Scaled

## 十四、为什么要 Softmax？

现在得到：

```text
scores:

[2.1, 5.7, 0.3, -1.2]
```

这还不是权重。

于是：

```python
weights = torch.softmax(scores, dim=-1)
```

变成：

```text
[0.026, 0.934, 0.037, 0.003]
```

满足：

```text
所有权重 ≥ 0

并且

总和 = 1
```

于是这些数字可以解释成：

> 当前 Token 应该从不同 Token 那里拿多少信息。

## 十五、最后为什么乘 V？

教授写：

\[
Attention(Q,K,V)
=
softmax\left(
\frac{QK^T}{\sqrt{d_k}}
\right)V
\]

林默终于能拆了。

第一部分：

\[
QK^T
\]

回答：

> 谁和谁相关？

第二部分：

```text
Softmax
```

回答：

> 每个人应该占多少权重？

第三部分：

```text
× V
```

回答：

> 按照这些权重，把真正的信息混合起来。

## 十八、PyTorch 手写一个最小 Attention

教授终于打开代码：

```python
import torch
import torch.nn.functional as F

Q = torch.randn(4, 8)
K = torch.randn(4, 8)
V = torch.randn(4, 8)

scores = Q @ K.T

scores = scores / (8 ** 0.5)

weights = F.softmax(scores, dim=-1)

output = weights @ V
```

林默问：

“shape 是什么？”

教授写：

```text
Q: [4, 8]
K: [4, 8]
V: [4, 8]
```

那么：

```text
K.T
→ [8, 4]
```

所以：

```text
Q @ K.T

[4,8] × [8,4]

→ [4,4]
```

也就是：

```text
Attention Score Matrix
```

再：

```text
weights @ V

[4,4] × [4,8]

→ [4,8]
```

最后：

> 每个 Token 仍然得到一个 8 维向量。

## 二十三、多头注意力是什么？

假设：

```text
hidden_dim = 512
num_heads = 8
```

那么：

```text
head_dim = 512 / 8 = 64
```

把表示拆成：

```text
Head 1 → 64维
Head 2 → 64维
Head 3 → 64维
...
Head 8 → 64维
```

每个 Head 都有自己的：

```text
Q
K
V
```

于是：

```text
Head 1
可能重点学习语法关系

Head 2
可能重点学习实体关系

Head 3
可能重点学习位置关系

...
```

注意：

这只是帮助理解。

现实中不能简单认定：

> 某个头一定就是“语法头”或“指代头”。

不同模型内部机制会更复杂。

## 二十四、多头怎么合回来？

每个 Head 输出：

```text
[batch, seq_len, head_dim]
```

8 个 Head：

```text
8 × 64 = 512
```

拼接：

```text
Concat
```

得到：

```text
[batch, seq_len, 512]
```

再经过：

```text
W_O
```

一个输出投影。

所以整体：

```text
X
 ↓
分成多个 Head
 ↓
各自 Attention
 ↓
Concat
 ↓
Linear
 ↓
输出
```

## 二十八、Causal Mask

假设有四个 Token：

```text
A B C D
```

标准 Self-Attention：

```text
A 可以看 A B C D
B 可以看 A B C D
C 可以看 A B C D
D 可以看 A B C D
```

但是 GPT：

```text
A 只能看 A

B 能看 A B

C 能看 A B C

D 能看 A B C D
```

形成：

```text
      A   B   C   D

A     ✓   ×   ×   ×
B     ✓   ✓   ×   ×
C     ✓   ✓   ✓   ×
D     ✓   ✓   ✓   ✓
```

这就是：

> 下三角 Mask。

---

## 二十九、Mask 是怎么实现的？

在 Softmax 之前。

原始 Score：

```text
[
 [2.1, 3.2, 1.4, 5.1],
 ...
]
```

对于未来位置：

加入：

```text
-inf
```

例如：

```text
[
 [2.1, -inf, -inf, -inf],
 [1.2,  3.1, -inf, -inf],
 ...
]
```

Softmax 后：

```text
exp(-inf) = 0
```

所以未来 Token 权重：

```text
0
```

模型就“看不见”未来。

## 三十、Padding Mask 和 Causal Mask 不一样

这是很容易混淆的。

Padding Mask：

```text
别看 PAD。
```

Causal Mask：

```text
别看未来。
```

一个解决：

```text
无效位置
```

一个解决：

```text
信息泄露
```

有时候两种 Mask 会同时存在。

## 三十一、一个真正接近 Transformer 的 Attention 模块

教授写：

```python
import torch
import torch.nn as nn
import torch.nn.functional as F


class SelfAttention(nn.Module):

    def __init__(self, hidden_dim):
        super().__init__()

        self.q_proj = nn.Linear(
            hidden_dim,
            hidden_dim
        )

        self.k_proj = nn.Linear(
            hidden_dim,
            hidden_dim
        )

        self.v_proj = nn.Linear(
            hidden_dim,
            hidden_dim
        )

    def forward(self, x):

        Q = self.q_proj(x)
        K = self.k_proj(x)
        V = self.v_proj(x)

        d = Q.size(-1)

        scores = (
            Q @ K.transpose(-2, -1)
        ) / (d ** 0.5)

        weights = F.softmax(
            scores,
            dim=-1
        )

        output = weights @ V

        return output
```

林默看着。

突然觉得那个经典公式没那么可怕了。

因为每一行他都知道为什么。

## 三十二、公式现在可以读成人话了

经典公式：

\[
Attention(Q,K,V)
=
softmax
\left(
\frac{QK^T}{\sqrt{d_k}}
\right)V
\]

林默现在会翻译：

```text
Q
↓
当前 Token 想找什么


K
↓
其他 Token 提供什么匹配特征


QKᵀ
↓
两两计算匹配程度


÷ √d
↓
防止数值过大


Softmax
↓
把匹配分数变成注意力权重


× V
↓
按照权重把信息聚合回来
```
