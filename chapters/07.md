> 阅读提示：Adam 并非在所有任务上优于 SGD；效果取决于模型、数据与调参。学习率调度器也不是训练必需品：StepLR、CosineAnnealingLR 的调用频率应与 step_size、T_max 的单位一致；ReduceLROnPlateau 则根据验证指标调用。

## 一、训练模型其实就是下山

假设模型只有一个参数：

\[
w
\]

Loss：

\[
L(w)
\]

图像：

```text
Loss

 ^
 |
 |       *
 |      / \
 |     /   \
 |    /     \
 |___/       \____

             w
```

现在：

```text
w = 10
```

但是最低点：

```text
w = 2
```

怎么办？

需要知道：

> 当前方向哪个地方下降最快。

这就是：

### Gradient（梯度）

---

## 二、梯度是什么？

上一章我们讲：

\[
\frac{\partial L}{\partial w}
\]

它表示：

> 参数变化一点，Loss 会怎么变化。

例如：

如果：

\[
\frac{\partial L}{\partial w}=5
\]

说明：

当 w 增大：

Loss 增大。

所以：

应该减少 w。

于是：

\[
w=w-\eta \frac{\partial L}{\partial w}
\]

其中：

\[
\eta
\]

就是：

### Learning Rate（学习率）

---

## 三、学习率就是步子大小

教授画两个人下山。

第一个：

```text
小步：

↓
↓
↓
↓
```

第二个：

```text

        ↙

              ↘
```

林默马上明白。

“学习率太大，会不会跨过最低点？”

教授点头。

---

### 情况一：学习率太大

例如：

```text
lr = 10
```

真正最低点：

```text
      ↓
     ★
```

但是一步：

```text

──────────────→

```

```text

  ↓
右边
  ↓
左边
  ↓
右边
```

Loss：

```text

...
```

模型不收敛。

---

### 情况二：学习率太小

例如：

```text

```

每次：

```text
↓
一点点

↓
一点点
```

可能训练几天：

还没走到山谷。

---

所以：

学习率是训练中最重要的超参数之一。

## 四、最原始的优化器：SGD

教授写：

```python
optimizer = torch.optim.SGD(
    model.parameters(),
    lr=0.01
)
```

SGD：

> Stochastic Gradient Descent

随机梯度下降。

最简单公式：

\[
w_{t+1}=w_t-\eta g_t
\]

其中：

```text
w_t

当前参数


g_t

当前梯度
```

翻译成人话：

```text
现在在哪里？

↓

看一下坡度

↓

往下降方向走一步
```

---

## 五、为什么叫随机？

林默问：

“哪里随机？”

教授回答：

“因为我们通常不是使用整个 Dataset 算梯度。”

回忆上一章：

```text
100万数据

↓

batch_size=64
```

一次：

```text
64条数据
```

计算：

```python
loss.backward()
```

得到：

```text
batch梯度
```

而不是：

```text
100万数据整体梯度
```

所以叫：

> Stochastic。

更严格说，现代深度学习常用的是 mini-batch SGD。

---

## 六、SGD 的问题：像醉汉下山

教授画：

```text
最低点

        ★


路径：

   ↘
      ↙
        ↘
          ↙
             ★
```

为什么？

因为：

每个 Batch 不一样。

Batch 1：

```text
方向：
往左
```

Batch 2：

```text
方向：
往右
```

Batch 3：

```text
方向：
往左下
```

梯度有噪声。

所以 SGD：

```text
效率高

但是摇摇晃晃
```

林默问：

“有没有办法让它有一点惯性？”

教授笑了。

“这就是 Momentum。”

---

## 七、Momentum：给小球加惯性

教授画一个球：

```text
      ○
     /
    /
   /
  ★
```

普通 SGD：

每一步：

看当前坡度。

Momentum：

不仅看当前坡度。

还记住：

> 我之前往哪里运动。

---

数学：

普通 SGD：

\[
v_t=g_t
\]

Momentum：

\[
v_t=\beta v_{t-1}+g_t
\]

然后：

\[
w=w-\eta v_t
\]


这里：

```text
v

速度
```

---

## 八、为什么 Momentum 有用？

假设：

连续几个梯度：

```text
↓
↓
↓
```

Momentum：

速度不断累积：

```text
↓↓↓↓
```

所以：

快速通过平坦区域。


如果梯度左右摇摆：

```text
←
→
←
→
```

过去的速度会抵消：

减少震荡。

所以：

Momentum：

```text
加速正确方向

减少随机震动
```

“那 Adam 又是什么？”

教授写：

### Adam

> Adaptive Moment Estimation

简单理解：

> Momentum + 自动调整每个参数学习率。

## 十、为什么需要不同学习率？

假设模型：

有两个参数：

```text
w1

w2
```

训练过程中：

参数1：

梯度：

```text
0.001
0.002
0.003
```

变化很慢。

参数2：

梯度：

```text
10
20
30
```

变化巨大。

如果统一：

```python
lr=0.001
```

可能：

参数1：

```text
几乎不动
```

参数2：

```text
跳来跳去
```

所以 Adam 想：

“每个参数应该有自己的步长。”

---

## 十一、Adam 的核心思想

Adam 保存两个东西。

### 1. 一阶矩

类似 Momentum：

记录：

> 梯度平均方向

叫：

\[
m_t
\]

可以理解：

```text
过去梯度趋势
```

---

### 2. 二阶矩

记录：

> 梯度大小变化

叫：

\[
v_t
\]

可以理解：

```text
这个参数最近波动大不大
```

---

然后：

如果某个参数：

梯度一直很大：

Adam：

```text
降低步子
```

如果某个参数：

梯度很小：

Adam：

```text
适当放大
```

所以：

> Adam 会给不同参数不同有效学习率。

---

## 十三、AdamW 为什么多一个 W？

林默问：

“AdamW 和 Adam 差在哪？”

教授写：

```text
Weight Decay
```

中文：

> 权重衰减。

---

先说为什么需要它。

假设模型参数：

```text
w=100
```

模型可能：

过度依赖这个参数。

导致：

> 过拟合。

希望：

参数不要太大。

于是加入：

\[
Loss'=Loss+\lambda ||w||^2
\]


意思：

除了让预测正确。

还要求：

> 参数不要乱膨胀。

---

## 十四、AdamW 的改进

Adam：

在传统 Adam 的耦合式 L2 正则实现中，把 weight_decay 对应的项加入梯度；未设置权重衰减时不存在这一项。

AdamW：

把：

```text
参数更新

和

权重衰减
```

分开。

实际效果通常更好。

所以：

现在训练 Transformer：

经常看到：

```text
optimizer = AdamW(...)
```

林默问：

---

后期：

```text
只差一点
```

希望：

```text

```

学习率变化：

```text

0.001
 |
```

这就是：

> Learning Rate Scheduler

## 十六、常见 Scheduler

### StepLR

每隔几个 Epoch 降低：

```python
scheduler = torch.optim.lr_scheduler.StepLR(
    optimizer,
    step_size=10,
    gamma=0.1
)
```

意思：

每 10 个 epoch：

学习率 ×0.1。

---

### Cosine Annealing

余弦下降：

```text
lr

高
 \
  \
   \
    \
     低
```

大模型训练非常常见。

---

### Warmup

Transformer 常见。

刚开始：

不要直接大 lr。

例如：

```text
epoch

0:
0.00001

10:
0.001
```

为什么？

因为模型刚开始参数随机。

太大的更新可能破坏训练。

所以：

先热身。

---

## 十七、一个真实训练配置

教授写：

```python
model = MyModel()


optimizer = torch.optim.AdamW(
    model.parameters(),
    lr=3e-4,
    weight_decay=0.01
)


scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(
    optimizer,
    T_max=100
)
```

训练：

```python
for epoch in range(100):

    for x,y in loader:

        optimizer.zero_grad()

        pred=model(x)

        loss=loss_fn(pred,y)

        loss.backward()

        optimizer.step()


    scheduler.step()
```

## 十八、为什么 scheduler.step() 在后面？

林默注意：

因为：


通常：

然后：

## 十九、梯度爆炸与梯度裁剪

教授突然写：

```text
Gradient Explosion
```

林默皱眉：

“不是刚说梯度消失？”

“深度学习两个极端都有。”

---

梯度太大：

```text
gradient:

1000000
```

更新：

\[
w=w-\eta g
\]

可能：

参数直接飞走。

Loss：

```text
10
100
10000
∞
```

---

解决：

Gradient Clipping。

PyTorch：

```python
torch.nn.utils.clip_grad_norm_(
    model.parameters(),
    max_norm=1.0
)
```

意思：

如果梯度太大：

限制一下。

---

训练：

```python
loss.backward()


torch.nn.utils.clip_grad_norm_(
    model.parameters(),
    1.0
)


optimizer.step()
```
