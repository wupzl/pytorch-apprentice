## 一、先回到 `nn.Linear`

昨天我们写过：

```python
layer = nn.Linear(2, 4)
```

它干的事情，本质上就是：

\[
y=Wx+b
\]

一维情况下更简单：

\[
y=wx+b
\]

比如：

\[
y=2x+1
\]

画出来：

```text
y
│
│           /
│         /
│       /
│     /
│   /
│ /
└──────────────── x
```

永远是一条直线。

参数 `w` 可以控制：

> **斜率。**

参数 `b` 可以控制：

> **上下平移。**

例如：

```text
w = 1       /
           /

w = 3         /
             /
            /
           /

w = -1    \
           \
            \
```

但无论怎么调整：

> **它永远不会弯。**

## 二、那我堆两层呢？

林默说：

“一个 Linear 不行，那两个呢？”

教授写：

```python
fc1 = nn.Linear(1, 10)
fc2 = nn.Linear(10, 1)
```

看起来已经很高级了：

```text
输入 x

   │
   ▼

○ ○ ○ ○ ○ ○ ○ ○ ○ ○
       第一层

   │
   ▼

   ○
 第二层

   │
   ▼

输出 y
```

十个隐藏神经元。

应该很厉害吧？

可教授开始推公式。

第一层：

\[
h=W_1x+b_1
\]

第二层：

\[
y=W_2h+b_2
\]

代进去：

\[
y=W_2(W_1x+b_1)+b_2
\]

展开：

\[
y=W_2W_1x+W_2b_1+b_2
\]

现在定义：

\[
W'=W_2W_1
\]

以及：

\[
b'=W_2b_1+b_2
\]

于是：

\[
y=W'x+b'
\]

教授把粉笔一扔。

“结束。”

林默：

“……”

两层 Linear：

```text
Linear
   ↓
Linear
```

最终仍然等价于：

```text
一个 Linear
```

## 五、ReLU 是什么？

教授写：

\[
ReLU(x)=\max(0,x)
\]

林默：

“就这？”

“就这。”

也就是说：

```text
输入 -5 → 0
输入 -2 → 0
输入 -1 → 0
输入  0 → 0
输入  1 → 1
输入  2 → 2
输入  5 → 5
```

Python 思维就是：

```python
def relu(x):
    return max(0, x)
```

PyTorch：

```python
x = torch.relu(x)
```

或者：

```python
relu = nn.ReLU()
x = relu(x)
```

它的图像是：

```text
y
│
│                /
│              /
│            /
│          /
│        /
│──────●──────────── x
│
│
```

当：

\[
x<0
\]

输出：

\[
0
\]

当：

\[
x>0
\]

输出：

\[
x
\]

林默盯着那个折角。

“它……”

“拐弯了。”

教授点头。

> **这一个小小的折角，就是神经网络拥有复杂表达能力的关键之一。**

## 六、Linear + ReLU 到底在干什么？

假设：

\[
z=wx+b
\]

然后：

\[
y=ReLU(z)
\]

比如：

\[
z=2x-4
\]

那么：

\[
y=ReLU(2x-4)
\]

什么时候开始大于 0？

\[
2x-4>0
\]

所以：

\[
x>2
\]

于是图像：

```text
y
│
│                  /
│                /
│              /
│            /
│──────────●──────────── x
           2
```

在 `x=2` 的地方出现一个：

> **拐点。**

## 七、一个 ReLU 一个拐点，那很多呢？

教授突然画了三个神经元。

第一个：

\[
h_1=ReLU(x-1)
\]

第二个：

\[
h_2=ReLU(x-3)
\]

第三个：

\[
h_3=ReLU(x-5)
\]

分别意味着：

```text
h1 在 x=1 开始工作
h2 在 x=3 开始工作
h3 在 x=5 开始工作
```

然后再让下一层把它们组合起来：

\[
y=w_1h_1+w_2h_2+w_3h_3+b
\]

你就可以得到：

```text
y
│
│              /
│        _____/
│       /
│  ____/
│ /
│/
└────────────────── x
   1    3    5
```

林默突然明白了。

“每个神经元都可以制造一个不同位置、不同方向的变化。”

“然后下一层把这些变化组合起来。”

“对。”

神经元越来越多：

```text
很多 Linear
     +
很多 ReLU
     ↓
制造大量折线片段
     ↓
组合
     ↓
逼近复杂函数
```

比如真正的曲线：

```text
        ~~~~~~~
     ~~~
   ~~
 ~~
```

神经网络可能用很多很小的折线去逼近：

```text
        __
      _/  \_
    _/      \_
  _/
_/
```

片段足够多以后，你肉眼看上去就越来越像一条曲线。

## 八、一个非常重要的概念：隐藏层

教授重新写昨天的模型：

```python
class MyNet(nn.Module):

    def __init__(self):
        super().__init__()

        self.fc1 = nn.Linear(2, 4)
        self.fc2 = nn.Linear(4, 1)

    def forward(self, x):

        x = self.fc1(x)
        x = torch.relu(x)
        x = self.fc2(x)

        return x
```

结构：

```text
输入层
x1  x2
│   │
└─┬─┘
  ▼

Linear(2, 4)

  ▼

h1 h2 h3 h4
│  │  │  │
└──┴──┴──┘
    ▼

   ReLU

    ▼

Linear(4, 1)

    ▼

   输出
```

中间：

```text
h1 h2 h3 h4
```

通常叫：

> **Hidden Layer——隐藏层。**

为什么叫隐藏层？

因为：

```text
输入 x
```

是我们能看到的数据。

```text
输出 y
```

也是我们关心的结果。

但是中间的：

```text
h1 h2 h3 h4
```

并不是人工直接提供的标签。

它们是模型内部学习出来的：

> **中间表示。**

## 十一、那为什么一定是 ReLU？

林默又问。

“非线性有很多吧？”

“当然。”

教授写下三个名字：


---

### Sigmoid

公式：

\[
\sigma(x)=\frac{1}{1+e^{-x}}
\]

图像大概：

```text
1 │                ______
  │             __/
  │           _/
  │         _/
  │       _/
  │_____/
0 └──────────────────── x
```

它可以把任意实数压到：

\[
(0,1)
\]

所以看起来特别像：

```text
概率
```

比如：

```text
0.01
0.35
0.82
0.99
```

但要小心：

> Sigmoid 的输出可以解释成概率，需要具体任务和损失函数等条件配合，并不是“见到 Sigmoid 就一定是概率”。

## 十二、Sigmoid 的一个问题：梯度容易变小

教授在曲线两端画圈：

```text
          ___________
       __/
     _/
   _/
__/
```

当输入特别大：

```text
x = 100
```

Sigmoid 已经非常接近：

```text
1
```

曲线几乎变平。

而导数是什么？

> **斜率。**

曲线很平：

```text
斜率 ≈ 0
```

也就是：

```text
gradient ≈ 0
```

林默立刻联想到上一章：

```text
参数更新量
=
learning_rate × gradient
```

如果：

```text
gradient ≈ 0
```

那么：

```text
参数几乎不更新
```

“所以深层网络反向传播的时候，梯度可能越来越小？”

“对，这就是经典的——”

> **梯度消失（Vanishing Gradient）**

的一部分来源。

---

## 十三、ReLU 为什么流行？

再看：

\[
ReLU(x)=\max(0,x)
\]

当：

\[
x>0
\]

时：

\[
ReLU(x)=x
\]

它的导数：

\[
ReLU'(x)=1
\]

所以正区间不会像 Sigmoid 饱和区那样天然把梯度压得很小。

而且计算极其简单：

```text
x > 0 ?

是 → x
否 → 0
```

因此 ReLU 长期以来是非常常见的激活函数。

不过教授马上补了一句：

“不要记成‘ReLU 没有梯度问题’。”

因为当：

\[
x<0
\]

时：

\[
ReLU(x)=0
\]

导数也是：

\[
0
\]

如果一个神经元长期落在负区间，就可能一直输出 0、梯度也为 0。

这叫：

> **Dying ReLU。**

## 十四、神经网络训练，其实是在移动“折线”

教授重新画：

```text
Linear
↓
ReLU
↓
Linear
↓
ReLU
↓
Linear
```

训练开始：

```text
随机 weight
随机 bias
```

所以一开始模型形成的函数可能乱七八糟：

```text
预测
│
│   /\__
│__/    \____
│
└──────────────── x
```

然后：

```python
loss.backward()
```

计算：

> 每个 `weight` 和 `bias` 改一点，会让 Loss 怎么变化？

再：

```text
optimizer.step()
```

修改：

```text
weight
bias
```

这些参数一变：

```text
Linear 的斜率变了
Linear 的位置变了
↓
ReLU 的拐点位置也可能变化
↓
整个网络表达的函数发生变化
```

然后继续：

```text
预测
→ Loss
→ backward
→ step
→ 预测
→ Loss
→ backward
→ step
...
```

于是模型表示的函数逐渐靠近训练数据要求的规律。

## 十六、把网络写得更漂亮：`nn.Sequential`

教授看着之前的代码：

```python
class MyNet(nn.Module):

    def __init__(self):
        super().__init__()

        self.fc1 = nn.Linear(2, 4)
        self.fc2 = nn.Linear(4, 1)

    def forward(self, x):
        x = self.fc1(x)
        x = torch.relu(x)
```

“如果网络只是按顺序执行，可以简单一点。”

```python

            nn.Linear(2, 4),
            nn.ReLU(),
            nn.Linear(4, 1)
        )

    def forward(self, x):
        return self.net(x)
```

甚至直接：

```python
model = nn.Sequential(
    nn.Linear(2, 4),
    nn.ReLU(),
    nn.Linear(4, 1)
)
```
