一、先回到 nn.Linear

昨天我们写过：

layer = nn.Linear(2, 4)

它干的事情，本质上就是：

y=Wx+b y=Wx+b

一维情况下更简单：

y=wx+b y=wx+b

比如：

y=2x+1 y=2x+1

画出来：

y
│
│           /
│         /
│       /
│     /
│   /
│ /
└──────────────── x

永远是一条直线。

参数 w 可以控制：

斜率。

参数 b 可以控制：

上下平移。

例如：

w = 1       /
           /

w = 3         /
             /
            /
           /

w = -1    \
           \
            \

但无论怎么调整：

它永远不会弯。

二、那我堆两层呢？

林默说：

“一个 Linear 不行，那两个呢？”

教授写：

fc1 = nn.Linear(1, 10)
fc2 = nn.Linear(10, 1)

看起来已经很高级了：

输入 x

   │
   ▼

○ ○ ○ ○ ○ ○ ○ ○ ○ ○
       第一层

   │
   ▼

   ○
 第二层

   │
   ▼

输出 y

十个隐藏神经元。

应该很厉害吧？

可教授开始推公式。

第一层：

h=W1x+b1 h=W_1x+b_1

第二层：

y=W2h+b2 y=W_2h+b_2

代进去：

y=W2(W1x+b1)+b2 y=W_2(W_1x+b_1)+b_2

展开：

y=W2W1x+W2b1+b2 y=W_2W_1x+W_2b_1+b_2

现在定义：

W′=W2W1 W'=W_2W_1

以及：

b′=W2b1+b2 b'=W_2b_1+b_2

于是：

y=W′x+b′ y=W'x+b'

教授把粉笔一扔。

“结束。”

林默：

“……”

两层 Linear：

Linear
   ↓
Linear

最终仍然等价于：

一个 Linear

四、神经网络需要一个“破坏者”

教授在两个 Linear 中间插入一个东西：

x = self.fc1(x)
x = torch.relu(x)
x = self.fc2(x)

结构变成：

Linear
   ↓
 ReLU
   ↓
Linear

林默看着那个熟悉的名字。

“就是昨天的 ReLU。”

“对。”

“它负责破坏线性。”

五、ReLU 是什么？

教授写：

ReLU(x)=max⁡(0,x) ReLU(x)=\max(0,x)

林默：

“就这？”

“就这。”

也就是说：

输入 -5 → 0
输入 -2 → 0
输入 -1 → 0
输入  0 → 0
输入  1 → 1
输入  2 → 2
输入  5 → 5

Python 思维就是：

def relu(x):
    return max(0, x)

PyTorch：

x = torch.relu(x)

或者：

relu = nn.ReLU()
x = relu(x)

它的图像是：

y
│
│                /
│              /
│            /
│          /
│        /
│──────●──────────── x
│
│

当：

x<0 x<0

输出：

0 0

当：

x>0 x>0

输出：

x x

林默盯着那个折角。

“它……”

“拐弯了。”

教授点头。

这一个小小的折角，就是神经网络拥有复杂表达能力的关键之一。

六、Linear + ReLU 到底在干什么？

假设：

z=wx+b z=wx+b

然后：

y=ReLU(z) y=ReLU(z)

比如：

z=2x−4 z=2x-4

那么：

y=ReLU(2x−4) y=ReLU(2x-4)

什么时候开始大于 0？

2x−4>0 2x-4>0

所以：

x>2 x>2

于是图像：

y
│
│                  /
│                /
│              /
│            /
│──────────●──────────── x
           2

在 x=2 的地方出现一个：

拐点。

七、一个 ReLU 一个拐点，那很多呢？

教授突然画了三个神经元。

第一个：

h1=ReLU(x−1) h_1=ReLU(x-1)

第二个：

h2=ReLU(x−3) h_2=ReLU(x-3)

第三个：

h3=ReLU(x−5) h_3=ReLU(x-5)

分别意味着：

h1 在 x=1 开始工作
h2 在 x=3 开始工作
h3 在 x=5 开始工作

然后再让下一层把它们组合起来：

y=w1h1+w2h2+w3h3+b y=w_1h_1+w_2h_2+w_3h_3+b

你就可以得到：

y
│
│              /
│        _____/
│       /
│  ____/
│ /
│/
└────────────────── x
   1    3    5

林默突然明白了。

“每个神经元都可以制造一个不同位置、不同方向的变化。”

“然后下一层把这些变化组合起来。”

“对。”

神经元越来越多：

很多 Linear
     +
很多 ReLU
     ↓
制造大量折线片段
     ↓
组合
     ↓
逼近复杂函数

比如真正的曲线：

        ~~~~~~~
     ~~~
   ~~
 ~~

神经网络可能用很多很小的折线去逼近：

        __
      _/  \_
    _/      \_
  _/
_/

片段足够多以后，你肉眼看上去就越来越像一条曲线。

八、一个非常重要的概念：隐藏层

教授重新写昨天的模型：

class MyNet(nn.Module):

    def __init__(self):
        super().__init__()

        self.fc1 = nn.Linear(2, 4)
        self.fc2 = nn.Linear(4, 1)

    def forward(self, x):

        x = self.fc1(x)
        x = torch.relu(x)
        x = self.fc2(x)

        return x

结构：

输入层
x1  x2
│   │
└─┬─┘
  ▼

Linear(2, 4)

  ▼

h1 h2 h3 h4
│  │  │  │
└──┴──┴──┘
    ▼

   ReLU

    ▼

Linear(4, 1)

    ▼

   输出

中间：

h1 h2 h3 h4

通常叫：

Hidden Layer——隐藏层。

为什么叫隐藏层？

因为：

输入 x

是我们能看到的数据。

输出 y

也是我们关心的结果。

但是中间的：

h1 h2 h3 h4

并不是人工直接提供的标签。

它们是模型内部学习出来的：

中间表示。

教授给了一个更现实的例子。

像素

像素

但是模型经过一层层变换：

原始像素
   ↓

   ↓

但核心思想成立：

隐藏层是在不断把数据转换成更适合完成任务的表示。

这也是为什么：

深度神经网络不仅是在“拟合答案”，还在学习如何表示数据。

十一、那为什么一定是 ReLU？

林默又问。

“非线性有很多吧？”

“当然。”

教授写下三个名字：

Sigmoid
Tanh
ReLU

Sigmoid

公式：

σ(x)=11+e−x \sigma(x)=\frac{1}{1+e^{-x}}

图像大概：

1 │                ______
  │             __/
  │           _/
  │         _/
  │       _/
  │_____/
0 └──────────────────── x

它可以把任意实数压到：

(0,1) (0,1)

所以看起来特别像：

概率

比如：

0.01
0.35
0.82
0.99

但要小心：

Sigmoid 的输出可以解释成概率，需要具体任务和损失函数等条件配合，并不是“见到 Sigmoid 就一定是概率”。

十二、Sigmoid 的一个问题：梯度容易变小

教授在曲线两端画圈：

          ___________
       __/
     _/
   _/
__/

当输入特别大：

x = 100

Sigmoid 已经非常接近：

1

曲线几乎变平。

而导数是什么？

斜率。

曲线很平：

斜率 ≈ 0

也就是：

gradient ≈ 0

林默立刻联想到上一章：

参数更新量
=
learning_rate × gradient

如果：

gradient ≈ 0

那么：

参数几乎不更新

“所以深层网络反向传播的时候，梯度可能越来越小？”

“对，这就是经典的——”

梯度消失（Vanishing Gradient）

的一部分来源。

十三、ReLU 为什么流行？

再看：

ReLU(x)=max⁡(0,x) ReLU(x)=\max(0,x)

当：

x>0 x>0

时：

ReLU(x)=x ReLU(x)=x

它的导数：

ReLU′(x)=1 ReLU'(x)=1

所以正区间不会像 Sigmoid 饱和区那样天然把梯度压得很小。

而且计算极其简单：

x > 0 ?

是 → x
否 → 0

因此 ReLU 长期以来是非常常见的激活函数。

不过教授马上补了一句：

“不要记成‘ReLU 没有梯度问题’。”

因为当：

x<0 x<0

时：

ReLU(x)=0 ReLU(x)=0

导数也是：

0 0

如果一个神经元长期落在负区间，就可能一直输出 0、梯度也为 0。

这叫：

Dying ReLU。

十四、神经网络训练，其实是在移动“折线”

教授重新画：

Linear
↓
ReLU
↓
Linear
↓
ReLU
↓
Linear

训练开始：

随机 weight
随机 bias

所以一开始模型形成的函数可能乱七八糟：

预测
│
│   /\__
│__/    \____
│
└──────────────── x

然后：

loss.backward()

计算：

每个 weight 和 bias 改一点，会让 Loss 怎么变化？

再：

optimizer.step()

修改：

weight
bias

这些参数一变：

Linear 的斜率变了
Linear 的位置变了
↓
ReLU 的拐点位置也可能变化
↓
整个网络表达的函数发生变化

然后继续：

预测
→ Loss
→ backward
→ step
→ 预测
→ Loss
→ backward
→ step
...

于是模型表示的函数逐渐靠近训练数据要求的规律。

十六、把网络写得更漂亮：nn.Sequential

教授看着之前的代码：

class MyNet(nn.Module):

    def __init__(self):
        super().__init__()

        self.fc1 = nn.Linear(2, 4)
        self.fc2 = nn.Linear(4, 1)

    def forward(self, x):
        x = self.fc1(x)
        x = torch.relu(x)
        x = self.fc2(x)
        return x

“如果网络只是按顺序执行，可以简单一点。”

class MyNet(nn.Module):

    def __init__(self):
        super().__init__()

        self.net = nn.Sequential(
            nn.Linear(2, 4),
            nn.ReLU(),
            nn.Linear(4, 1)
        )

    def forward(self, x):
        return self.net(x)

甚至直接：

model = nn.Sequential(
    nn.Linear(2, 4),
    nn.ReLU(),
    nn.Linear(4, 1)
)

林默看着：

nn.Sequential(
    nn.Linear(2, 4),
    nn.ReLU(),
    nn.Linear(4, 1)
)

突然觉得神经网络第一次有了一种搭积木的感觉：

Linear
  ↓
ReLU
  ↓
Linear

十七、这东西其实有名字：MLP

教授在黑板上写：

MLP

全称：

Multi-Layer Perceptron

中文通常叫：

多层感知机

典型结构：

输入
 ↓
Linear
 ↓
ReLU
 ↓
Linear
 ↓
ReLU
 ↓
Linear
 ↓
输出

例如：

model = nn.Sequential(
    nn.Linear(100, 256),
    nn.ReLU(),

    nn.Linear(256, 128),
    nn.ReLU(),

    nn.Linear(128, 10)
)

形状变化：

100
 ↓
256
 ↓
128
 ↓
10

这里：

100 → 输入特征维度
256 → 隐藏维度
128 → 隐藏维度
10  → 输出维度

教授停顿了一下。

“记住这个结构。”

“以后你学 Transformer，会再次看到类似的东西。”

林默一愣。

“Transformer 里面也有 MLP？”

“当然。”

“而且非常重要。”

现代 Transformer block 里通常存在类似：

Attention
   ↓
...
   ↓
MLP / FFN

不过其中的激活函数现代模型常见的已经不只是 ReLU，还会看到：

GELU
SiLU / Swish
SwiGLU

这些以后再讲。

神经网络之所以强，不只是因为“层数多”，而是因为多层可学习变换与非线性组合起来，可以形成复杂的函数。

十九、但林默发现了新的问题

他重新看向训练代码：

for epoch in range(1000):

    optimizer.zero_grad()

    pred = model(x)

    loss = loss_fn(pred, target)

    loss.backward()

    optimizer.step()

突然问：

“教授。”

“我们一直在说 loss。”

“但是——”

“这个 Loss 到底是谁规定的？”

教授停下脚步。

林默继续问：

“回归为什么经常用 MSE？”

“分类为什么又冒出来 CrossEntropy？”

“如果模型输出 10 个数字，怎么知道哪个数字代表猫？”

“还有我经常看到分类代码最后一层没有 Softmax，为什么 CrossEntropyLoss 又能直接算？”

教授慢慢转过身。

“很好。”

他在黑板上写：

Regression
    ↓
MSE

Classification
    ↓
Logits
    ↓
Softmax
    ↓
Cross Entropy
