一、训练模型其实就是下山

假设模型只有一个参数：

w w

Loss：

L(w) L(w)

图像：

Loss

 |       *
 |      / \

 |    /     \
 |___/       \____

             w

现在：

w = 10

但是最低点：

w = 2

怎么办？

需要知道：

当前方向哪个地方下降最快。

这就是：

Gradient（梯度）

二、梯度是什么？

上一章我们讲：

∂L∂w \frac{\partial L}{\partial w}

它表示：

参数变化一点，Loss 会怎么变化。

例如：

如果：

∂L∂w=5 \frac{\partial L}{\partial w}=5

说明：

当 w 增大：

Loss 增大。

所以：

应该减少 w。

于是：

w=w−η∂L∂w w=w-\eta \frac{\partial L}{\partial w}

其中：

η \eta

就是：

Learning Rate（学习率）

四、最原始的优化器：SGD

教授写：

optimizer = torch.optim.SGD(
    model.parameters(),
    lr=0.01
)

SGD：

Stochastic Gradient Descent

随机梯度下降。

最简单公式：

wt+1=wt−ηgt w_{t+1}=w_t-\eta g_t

其中：

w_t

当前参数


g_t

当前梯度

翻译成人话：

现在在哪里？

↓

↓

往下降方向走一步

五、为什么叫随机？

林默问：

“哪里随机？”

教授回答：

“因为我们通常不是使用整个 Dataset 算梯度。”

回忆上一章：

100万数据

↓

batch_size=64

一次：

64条数据

计算：

loss.backward()

得到：

batch梯度

而不是：

100万数据整体梯度

所以叫：

Stochastic。

更严格说，现代深度学习常用的是 mini-batch SGD。

七、Momentum：给小球加惯性

教授画一个球：

      ○
     /
    /
   /
  ★

普通 SGD：

每一步：

看当前坡度。

Momentum：

不仅看当前坡度。

还记住：

我之前往哪里运动。

数学：

普通 SGD：

vt=gt v_t=g_t

Momentum：

vt=βvt−1+gt v_t=\beta v_{t-1}+g_t

然后：

w=w−ηvt w=w-\eta v_t

这里：

v

速度

八、为什么 Momentum 有用？

假设：

连续几个梯度：

↓
↓
↓

Momentum：

速度不断累积：

↓↓↓↓

所以：

快速通过平坦区域。

如果梯度左右摇摆：

←
→
←
→

过去的速度会抵消：

减少震荡。

所以：

Momentum：

加速正确方向

减少随机震动

九、Adam 登场

林默看代码：

optimizer = torch.optim.Adam(
    model.parameters(),
    lr=0.001
)

“那 Adam 又是什么？”

教授写：

Adam

全称：

Adaptive Moment Estimation

简单理解：

Momentum + 自动调整每个参数学习率。

十、为什么需要不同学习率？

假设模型：

有两个参数：

w1

w2

训练过程中：

参数1：

梯度：

0.001
0.002
0.003

变化很慢。

参数2：

梯度：

10
20
30

变化巨大。

如果统一：

lr=0.001

可能：

参数1：

几乎不动

参数2：

跳来跳去

所以 Adam 想：

“每个参数应该有自己的步长。”

十一、Adam 的核心思想

Adam 保存两个东西。

1. 一阶矩

类似 Momentum：

记录：

梯度平均方向

叫：

mt m_t

可以理解：

过去梯度趋势

2. 二阶矩

记录：

梯度大小变化

叫：

vt v_t

可以理解：

这个参数最近波动大不大

然后：

如果某个参数：

梯度一直很大：

Adam：

降低步子

如果某个参数：

梯度很小：

Adam：

适当放大

所以：

Adam 会给不同参数不同有效学习率。

十二、SGD vs Momentum vs Adam

教授画表：

优化器 特点
SGD 简单，根据当前梯度走
Momentum 增加惯性，减少震荡
Adam 自适应学习率，训练方便

实际经验：

很多深度学习任务：

Adam / AdamW

↓

默认选择

尤其：

Transformer
LLM
RAG模型微调

大量使用：

AdamW

十三、AdamW 为什么多一个 W？

林默问：

“AdamW 和 Adam 差在哪？”

教授写：

Weight Decay

中文：

权重衰减。

先说为什么需要它。

假设模型参数：

w=100

模型可能：

过度依赖这个参数。

导致：

过拟合。

希望：

参数不要太大。

于是加入：

Loss′=Loss+λ∣∣w∣∣2 Loss'=Loss+\lambda ||w||^2

意思：

除了让预测正确。

还要求：

参数不要乱膨胀。

十四、AdamW 的改进

Adam：

在传统 Adam 的耦合式 L2 正则实现中，把 weight_decay 对应的项加入梯度；未设置权重衰减时不存在这一项。

AdamW：

把：

参数更新

和

权重衰减

分开。

实际效果通常更好。

所以：

现在训练 Transformer：

经常看到：

optimizer = AdamW(...)

需求不同。

十七、一个真实训练配置

教授写：

model = MyModel()


optimizer = torch.optim.AdamW(
    model.parameters(),
    lr=3e-4,
    weight_decay=0.01
)


scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(
    optimizer,
    T_max=100
)

训练：

for epoch in range(100):

    for x,y in loader:

        optimizer.zero_grad()

        pred=model(x)

        loss=loss_fn(pred,y)

        loss.backward()

        optimizer.step()


    scheduler.step()

十九、梯度爆炸与梯度裁剪

教授突然写：

Gradient Explosion

林默皱眉：

“不是刚说梯度消失？”

“深度学习两个极端都有。”

梯度太大：

gradient:

1000000

更新：

w=w−ηg w=w-\eta g

可能：

参数直接飞走。

Loss：

10
100
10000
∞

解决：

Gradient Clipping。

PyTorch：

torch.nn.utils.clip_grad_norm_(
    model.parameters(),
    max_norm=1.0
)

意思：

如果梯度太大：

限制一下。

训练：

loss.backward()


torch.nn.utils.clip_grad_norm_(
    model.parameters(),
    1.0
)


optimizer.step()
